# ECG Diagnostic Assistant Version 2 設計

## 1. 製品定義

Version 2は「AI画像診断アプリ」ではなく、医師が入力したガイドラインと条件だけを実行する**ルールベース心電図解析エンジン**である。診断ロジックへ生成AI、LLM、外部知識、自動補完を使用しない。

## 2. 現在の処理フロー

```text
画像
  ↓
医師が波形を確認
  ↓
主要所見を入力・修正
  ↓
ルールベース推論
  ↓
診断候補 → 鑑別 → 追加確認・追加検査 → 初期対応
```

画像は観察資料であり、医師確定前の値を診断条件として確定扱いしない。医師修正後は同一ルールエンジンを再実行する。

## 3. 将来のローカル画像解析

```text
画像
  ↓
ローカルモデルによる所見抽出
  ↓
医師確認・修正
  ↓
ルールベース推論
```

ローカルモデルが出力できるのは、画質、装着、心拍数、リズム、P波、PQ（PR）、QRS、軸、R波進行、Q波、ST、T波、U波、QT/QTcなどの観察所見と測定値だけとする。

ローカルモデルの出力Schemaには、診断候補、鑑別、緊急度、Red Flag、追加検査、初期対応、薬剤、治療を含めない。欠測値を正常値で補完しない。

## 4. ルール分類

Version 2の台帳は次の19分類を固定分類として扱う。

1. 撮影不良・電極装着
2. P波
3. PQ（内部データ名はPRを維持）
4. QRS
5. R波進行
6. 軸
7. Q波
8. ST
9. T波
10. U波
11. QT
12. 徐脈
13. 頻脈
14. 脚ブロック
15. WPW
16. Brugada
17. Wellens
18. 電解質
19. その他

内部フィールド名のPRは既存データ互換性のため変更せず、画面・台帳上はPQ（PR）と表記する。

## 5. ルール形式

各ルールは次の情報を必須とする。

```text
Rule ID
分類
IF（成立条件）
THEN（診断候補または評価結果）
重み
必要入力
追加確認項目
支持所見
矛盾所見
鑑別・代替説明
追加検査
初期対応
適用制限
出典
```

Rule IDは表示・テスト・監査に使う安定IDであり、医学的確率を表さない。重みは既存ルール間の表示強度であり、新しい診断閾値ではない。

## 6. 優先順位

複数ルールが同時成立した場合のVersion 2表示優先順位は次の通りとする。

```text
VF
  ＞ STEMI相当の急性冠動脈閉塞候補
  ＞ 完全房室ブロック／高度房室ブロック
  ＞ 重症高Kパターン
  ＞ Brugada pattern候補
  ＞ Wellens pattern候補
  ＞ その他
```

同一階層内では、既存の`mustNotMiss`、緊急度、支持所見数を用いる。循環動態不安定は候補順位とは別に最優先の初期対応を生成する。技術的制限が併存しても、上位候補を自動削除しない。

この段階では優先順位を設計として確定するだけで、既存医学判定条件の追加・削除・閾値変更は行わない。

## 7. 追加確認項目

必要入力が不足する場合は、単に「診断不能」で終了しない。該当ルールが要求する次の確認を具体的に表示する。

- V4Rを含む右側胸部誘導
- V7～V9
- 前回ECG比較
- 12誘導ECG再記録・経時変化
- 心エコー
- トロポニンなど、既存ルールに登録済みの検査
- QT/QU、T/U境界、P波、長いリズムストリップなどの再確認

追加確認項目は候補を確定する情報であり、不足を陰性所見へ変換しない。

## 8. 説明可能性

診断候補ごとに、最低限次を表示する。

```text
使用ルール: Rule-ST-001, Rule-T-002
支持所見
矛盾所見
追加確認項目
鑑別・代替説明
追加検査
初期対応
```

医師が所見を修正した場合は再計算し、成立しなくなったRule IDを候補から外す。医師による候補採用・除外と緊急度修正はルール入力の改変とは分離して記録する。

## 9. 禁止事項

- OpenAI、LLM、生成AIによる診断・鑑別・検査・対応生成
- 画像解析モデルによる診断名出力
- 未入力値の推測や正常値での補完
- 現在登録されていない医学知識、閾値、疾患ルールの追加
- ルール成立理由を表示しないブラックボックス判定

## 10. Version 2の完成条件

- 全ルールが台帳上でIF–THEN、必要入力、追加確認項目を持つ
- 統合候補が使用Rule IDを返す
- 医師修正後に候補、鑑別、追加検査、初期対応が再計算される
- 指定優先順位が回帰テストで固定される
- 画像解析境界のSchemaテストで診断出力を禁止する
- 既存ルールの全回帰テストが成功する

詳細な現在ルールは[`ecg-rule-catalog.md`](ecg-rule-catalog.md)、ローカル所見抽出モデルの将来要件は[`local-ecg-model-roadmap.md`](local-ecg-model-roadmap.md)を参照する。
